GeoDubber Help

1. Select a video file and optionally import timed subtitles (SRT / VTT / TXT).

2. Choose Fast / Balanced / Quality, set the character count or leave it on Auto, then press Start Dubbing.

3. When the Review window appears, listen to each original character sample, set gender and voice, and correct the Georgian translations.

4. Continue dubbing. After completion, download the MP4. The online output contains Georgian dubbing only, with no subtitles.

Stop safely stops the current task at a checkpoint and keeps completed work. Use Resume / open to continue a stopped project. Cancel and delete removes the project data but does not change the original file on your computer.

Web mode uses server CPU and the current lightweight online pipeline. It does not yet include every desktop-only model manager, custom F5 voice recording, YouTube URL import, or background separation setting.
